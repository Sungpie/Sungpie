# 안녕하세요, Sungpie입니다 👋

펌웨어와 임베디드 소프트웨어를 개발합니다.  
C, C++, Linux를 중심으로 하드웨어 제어부터 임베디드 리눅스와 디바이스 드라이버까지 폭넓게 탐구하고 있습니다.

## 주요 프로젝트

### [Motor Project](https://github.com/Sungpie/Motor-Project)
MCU 타이머와 인터럽트를 활용하는 모터 제어 프로젝트입니다.  
타이머 시작 시 발생한 의도치 않은 인터럽트의 원인을 분석하고 해결한 과정을 기록했습니다.

### [Vision Tracking Project](https://github.com/Sungpie/Vision_Tracking_Project)
선택한 인물을 카메라가 자동으로 추적하고, 차량을 수동으로 이동할 수 있는 팀 프로젝트입니다.  
영상 인식과 팬틸트·차량 제어를 연결해 하드웨어 시스템으로 구현했습니다.

### [Linux Device Driver](https://github.com/Sungpie/Linux_Device_Driver)
Jetson Orin Nano에서 엔코더, DC 모터, LED를 제어하는 팀 프로젝트입니다.  
유저 공간 제어와 커널 캐릭터 디바이스 드라이버 방식을 구현하고 비교했습니다.

### [FPGA Microwave Controller](https://github.com/Sungpie/project_microwave)
Verilog와 Basys 3 FPGA 보드를 이용해 전자레인지 동작을 구현한 프로젝트입니다.  
시간 설정과 카운트다운, 7세그먼트 표시, 부저 알림, 서보 모터 제어를 다룹니다.
